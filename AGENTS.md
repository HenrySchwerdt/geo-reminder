# AGENTS.md — working on Worktime

Worktime is a local-first work-time tracker with geofence reminders: an Expo app for iPhone and Android
(`apps/mobile`), an Apple Watch app (`apps/mobile/targets`), a Wear OS app (`apps/wear`) and a pure TypeScript
domain core (`packages/core`). The FigCraft design is in `design/`.

**Current task for the agent on the Mac: [docs/handover/codex-ios.md](docs/handover/codex-ios.md).**

## Setup and checks
```bash
npm install                          # repo root (npm workspaces, npm 11, Node 22)
npm test                             # core + app logic (Vitest)
npm run typecheck
cd apps/mobile && npx expo lint && npx -y expo-doctor
```
Run all of these before every commit; CI (`.github/workflows/ci.yml`) runs the same plus the iOS/Android bundle export.

## Conventions
- **Types come from zod schemas** (`packages/core/src/schema.ts`, `surfaces.ts`); never hand-write a type that a schema already defines.
- **Domain logic is pure and lives in `@worktime/core`** or in a feature's `.ts` files with Vitest tests. Screens in `src/app` stay thin.
- **State**: Zustand stores per feature, persisted synchronously to SQLite's key-value store and validated with zod on rehydrate.
- **The event log is append-only.** Corrections add events that `supersede` or `voids` older ones. Never update or delete stored events.
- **Time**: always pass an explicit IANA zone (`deviceTimeZone()`, helpers in `packages/core/src/time/zone.ts`). Never use `Date#getHours`/`getDate`/`setHours` for logic. A session belongs to the day of its clock-in, in its own zone.
- **Days without a check-out count for nothing** until fixed (`packages/core/src/time/complete.ts`). Every total must use `countedEvents`.
- **Surfaces** (widgets, Live Activity, watches) only render a `SurfaceSnapshot` and send `SurfaceCommand`s. They never compute or write history (`docs/technical/surfaces.md`).
- Match the surrounding code: feature folders, small functions, concise doc comments, English UI copy.
- `apps/mobile/ios` and `apps/mobile/android` are generated by `npx expo prebuild` and are **not committed**. Native changes go into config plugins, `modules/` or `targets/`.
- `expo prebuild` rewrites the `ios`/`android` scripts in `apps/mobile/package.json`; revert that before committing.
- Work on a branch and open a pull request to `main`. Don't push to `main` directly.
